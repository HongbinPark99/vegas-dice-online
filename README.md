# 🎲 Vegas Dice Online

보드게임 **라스베가스(Las Vegas Dice Game)** 규칙을 기반으로 만든 온라인 멀티플레이 웹게임입니다.
PC와 모바일 브라우저 모두 지원하며, 방 코드만 공유하면 친구들과 함께 플레이할 수 있습니다.

**플레이:** https://vegas-dice-online.onrender.com (무료 플랜 — 일정 시간 미사용 시 잠들었다가 재접속 시 최대 약 50초 후 깨어남)

## 게임 규칙 요약

- 카지노는 1~6번까지 총 6개, 각 카지노에는 시작할 때 1~3장의 지폐(1만~9만원)가 놓입니다.
- 각 플레이어는 주사위 8개를 가지고 시작합니다.
- 자기 차례에 남은 주사위를 모두 굴린 뒤, 나온 숫자 중 하나를 골라 **그 숫자가 나온 주사위 전부**를 해당 번호 카지노에 놓습니다.
- 모든 플레이어가 주사위를 다 놓으면 라운드 종료 → 각 카지노에서 주사위를 가장 많이 놓은 사람이 가장 비싼 지폐를 획득 (2등은 다음 지폐, ...).
- **동점이면 그 순위의 지폐는 소멸**하고, 못 나눠준 지폐는 다음 라운드로 이월됩니다.
- 총 4라운드 진행 후 누적 금액이 가장 많은 사람이 승리합니다.
- 2~6명 플레이 가능합니다. **2인 플레이는 더미(중립) 다이스 2세트, 3인 플레이는 1세트가 자동으로 추가되어** 실제 보드게임처럼 밸런스를 맞춥니다. 더미는 서버가 즉시 자동으로 굴리고 배치하며(가장 많이 나온 숫자를 선택), 최종 승자 판정에는 포함되지 않습니다.

## 실행 방법 (로컬)

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속 → 닉네임 입력 → "방 만들기" → 나온 4자리 코드를 친구에게 공유.
같은 네트워크(같은 Wi-Fi)에 있는 친구라면 내 PC의 IP로 접속하면 됩니다 (예: `http://192.168.0.5:3000`).

## 친구들과 인터넷으로 함께 하려면 (배포)

같은 공간이 아니라면 서버를 인터넷에 올려야 합니다. 무료로 가장 쉬운 방법 두 가지:

### 방법 A: Render.com (무료 웹서비스)
1. 이 폴더를 GitHub 저장소로 올립니다.
2. https://render.com 에서 "New Web Service" → 방금 만든 저장소 연결.
3. Build Command: `npm install`, Start Command: `npm start`.
4. 배포 완료되면 나오는 URL을 친구들에게 공유하면 끝!

### 방법 B: 빠른 임시 공유 (ngrok)
```bash
npm install -g ngrok   # 또는 https://ngrok.com 에서 설치
npm start               # 서버 실행 (3000번 포트)
ngrok http 3000         # 임시 외부 접속 URL 생성
```
ngrok이 알려주는 `https://xxxx.ngrok-free.app` 주소를 친구들에게 공유하면 바로 접속됩니다. (내 PC를 켜놓는 동안만 유지됩니다.)

배포까지 도와달라고 하시면 Render 계정 연결이나 GitHub 저장소 생성 같은 단계도 같이 진행해 드릴게요.

## 폴더 구조

```
vegas-dice-online/
├── server.js            # Express + Socket.IO 서버 엔트리포인트
├── server/
│   ├── game.js           # 라스베가스 게임 엔진 (카지노/지폐/주사위/라운드 판정)
│   └── rooms.js           # 방(로비) 생성/참가/시작 관리
├── public/
│   ├── index.html         # 화면 마크업 (시작/로비/게임/결과 오버레이)
│   ├── style.css           # 카지노 테마 스타일
│   └── client.js            # 소켓 통신 + 렌더링 로직
└── tests/
    ├── full_game_sim.js       # 4인 전체 게임 자동 시뮬레이션 (엔진 검증용)
    ├── lobby_rules_sim.js     # 로비 규칙(최소 인원/준비/방장 권한) 검증용
    └── dummy_variant_sim.js   # 2/3인 더미 다이스 변형 규칙 검증용
```
